### 两个 HTML 的区别

| 文件 | 是什么 | 什么时候看 |
|---|---|---|
| `design-full.html` | **逐屏设计规格**：每屏的结构 / 尺寸 / 文案 / 状态 / 数值 / 画布节点，文字密集，给实现和验收查细节用 | 实现某一屏、核对某个数值 |
| `prototype-visual/index.html` | **可点原型稿**：一个装满的 393×852 设备框，像真机一样逐步点击走流程，左侧按「入口 / 资产 / 账本 / 我的」分组跳屏，每屏下方带一条"本轮改了什么"的注释。<b>多态屏（`01` 两步骤五态：① 空号 / ① 已填 / ② 验证码 / ② 已填满 / ② 错误态；`02 首页` 四态：取出前 / 取出后 / 忍住 / 今日 0 支；`25` 三态）下方另有「状态」切换条</b>，点一下或按 `↑↓` 挨个走；`←→` 翻屏、`Esc` 返回。`#s07` 可深链直达某一屏，`#s08/1` 可直达某屏某状态，且**切屏即同步回 URL**（便于逐屏评审/截图/复制分享）。`09` 目标步进器、`12` 时段胶囊、`27` 库存步进、各页开关可真拨动（仅演示手感，不写数据口径）；弹层类屏幕**点遮罩即关闭**（`03/08/09/11/12/13/14/17/20/21/25/27`）。<b>`08 取出弹层`里两支烟是真可选的</b> —— 点哪支，弹层承诺行与落点 `23` 的数值一起变 | 看整体感觉、走流程、给非设计同学演示 |

## 三条不能破的规则

1. **颜色按语义分配，不按美观分配**。实心品牌绿 `#38665F` 只给「推荐选项」；墨色 `#1A211E` 只做文字色，不做填充色；暖琥珀 `#C26B32` 固定代表「代价」。
2. **破坏性操作里，安全选项才是主按钮**。危害警示、取出弹层、清空库存、删除记录四个场景，绿色永远给「不做那件事」。
3. **一次取出最多打断一次**。详见 `design-spec.md` →「干预分级」。
