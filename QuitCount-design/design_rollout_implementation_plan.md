## 1. 差异清单（设计稿 vs 现有代码）

按「改动性质」分四类。**A/B 是全端性改动，必须先行**；C/D 是逐屏改动，可并行。

### A. 模型与口径（全端性 · 最高优先级）

| # | 项 | 现有实现 | 设计稿（A1 · `design-spec.md` §4） | 影响面 |
|---|---|---|---|---|
| **A1** | 当日危害分 | `dailyHarmScore(todayTaken)` **只看支数**，分段 50 / 56 / 68 / 82… | `100 × (1 − 0.5^(n/5.2)) + clamp((T − 9n) × 0.5, −5, +10)`，**输入支数 + 焦油**，n=0 时恰好 0 | 首页横幅、03、05、10、17、21 |
| **A2** | 近期负担指数 | **不存在** | `0.88 × 前值 + 0.12 × 危害分`，λ=0.12，半衰期 5.42 天，23.4 天达 95% | 首页 Hero、15、24 |
| **A3** | 健康净值 | `100 − lungScore`（lungScore 是当日分段） | `100 − 近期负担指数`（随时间衰减的积累量） | 首页、15、24、10 模型页 |
| **A4** | 健康折算 | `cigarettes × 20` **分钟** | **`0.43 × 焦油 mg` → 元**（金额，非时间） | 账本拆分、08、11、21、25 |
| **A5** | 库存健康负债 | `stockCount × 20` 分钟 | **`0.43 × 库存焦油 mg` → 元**，现 −¥52.0 | 资产页 |
| **A6** | 包年增量 | `todayCigarettes / 20 / 365` | **不再出现在主界面** | 首页、10 |
| **A7** | 危害分档位 | 无五档（旧版是"高危/中等"） | `20/40/60/80` → 轻负担 / 偏低 / 中等 / 偏高 / 重负担 | 02、15、17、24 |
| **A8** | 干预触发基准 | 「达到干预线」（分数） | **用户自设目标**（默认 5 支）：首超 1–2 支弹 03；首超 ≥3 支弹 17（取代 03） | 03、17、08 |

> **⚠️ 2026-10-03 P0-1 修正**：原第 4 行写作 `28.7 × 0.88 + 42 × 0.12 → 42.4`，**该式字面值为 30.296，与期望不符**。

> **易错点**（写进测试注释）：今日成本 / 库存健康负债 / 累计花费是**三个不同时间尺度**，不能互相套用。曾经的 bug 是把资产页的健康负债做成了库存价值的镜像。

### 3.2 UI 验收三查（每阶段必查）

1. **实心绿独占**：整屏扫一遍，实心 `--sage-900` 只出现在**一个主按钮 + 一个 Tab**。
2. **代价色语义**：琥珀只用于「代价/警告」；危害分为 0 时**不得**出现琥珀横幅。
3. **破坏性安全项**：删除/清空/仍要取出弹窗里，**绿色主按钮指向安全选项**。

### 3.3 多尺寸

`390×844` 为基准；另覆盖 **一个小屏（如 360×780）+ 一个常规机 + 一个大屏**。窄屏允许说明文字换行，但**关键数值不得换行/截断**。内容超高必须可滚动；底部主操作不得被手势区遮挡。
