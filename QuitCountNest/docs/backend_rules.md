# 戒烟有数后端工程规则

> 状态：规范草案，2026-07-14。本文规定后端实现门禁；架构细节见 [后端技术设计](./backend_technical_design.md)，阶段执行见 [后端实施计划](./backend_implementation_plan.md)。

## 1. 规则优先级与冲突处理

1. `QuitCountHarmony/docs/product_spec.md`：最终产品规则源，决定范围、公式、交互边界、通知、合规与验收。
2. 已批准的安全、隐私、法务和数据治理要求：只能收紧实现，不能借此改变产品核心语义；冲突必须升级确认。
3. 已批准 OpenAPI、数据库迁移和 ADR：是后端契约与工程决策源。
4. 当前 Harmony 源码与阶段报告：是已落地证据，不是覆盖产品规格的规则源。
5. 本文与实施计划：约束工程执行。若与以上来源冲突，停止实现、记录差异、先修文档和契约，再改代码。

所有决策使用以下标记：**【已确认事实】**、**【建议选型】**、**【待产品/运维确认】**。不得把建议或待确认项写成已存在事实。

## 2. 服务端职责与非职责

### 2.1 必须负责

- 可选账户、认证会话、设备撤销和跨用户隔离。
- 资产、目标、可同步设置、不可变账本、同步游标与墓碑的云端 canonical 状态。
- 幂等、并发控制、冲突检测、审计、云端导出与账户删除高风险流程。
- 精确金额、UTC 时间、自然日上下文、公式模型版本和历史可追溯性。
- 健康检查、日志、指标、备份恢复、安全扫描和发布回滚门禁。

### 2.2 不得负责或首版不负责

- 不重新定义 Harmony UI、震动、Sheet、弹窗和本地交互。
- 不接管客户端 CSV 导出；未来云端导出必须明确命名和授权。
- 不发送严厉危害三连提醒或每日复盘 push，不阻止取烟。
- 不把登录/网络作为手机核心取烟、放回、账本查看的前置条件。
- 不提供医学诊断、治疗建议、羞辱/恐吓文案、社区、商城或购买推荐。

## 3. API 规则

### 3.1 兼容性与版本

- REST 基础路径固定为 `/api/v1`。删除/重命名字段、改变字段含义/单位、收窄合法值、改变默认行为均视为破坏性变更。
- 新增可选字段通常是兼容变更；客户端必须忽略未知响应字段，服务端默认拒绝未知写入字段。
- OpenAPI 3.0.3 是首期契约基线；实现、契约测试、示例和 Harmony adapter 必须同步。破坏性 diff 未批准不得发布。升级 OpenAPI 3.1 必须通过独立 ADR，并证明 Nest 生成、lint 和 Harmony client 工具链兼容。
- 当前框架主线固定为 NestJS 11。新增或修改代码必须以 NestJS 11 官方文档、migration guide 和项目已安装类型定义为准；禁止使用已标记 `deprecated` 的 API。依赖升级必须先通过编译、lint、单元/E2E 和契约回归，不得直接照搬旧版 NestJS 示例。
- 错误 `code` 稳定、机器可读；`message` 可本地化，不得让客户端依赖文案分支。

### 3.2 错误与状态码

- 错误统一包含 `code`、`message`、`requestId`、`retryable`，字段错误放 `details`。
- `400` DTO/语义错误，`401` 未认证，`403` 无权限，`404` 在无权访问时也可用于隐藏资源存在性，`409` 幂等/版本/领域冲突，`422` 可修正领域校验，`429` 限流，`5xx` 服务端故障。
- 不向客户端返回堆栈、SQL、内部路径、供应商响应全文或敏感配置。

### 3.3 幂等、并发与分页

- 所有可重试写请求必须接受 `Idempotency-Key`；同步项还必须有稳定 `clientMutationId`。幂等响应缓存可以过期，但账本事件 ID 与 `(userId, deviceId, clientMutationId)` 的领域唯一性不能过期。
- 同一幂等键和同一规范化 body 返回原结果；同键不同 body 返回 `IDEMPOTENCY_KEY_REUSED`。
- 普通可变资源用 `version` + `If-Match/baseVersion` 乐观并发。资产必须拆分 `profileVersion` 与 `stockRevision`：资料/默认项只比较 `profileVersion`，库存只由账本事务推进 `stockRevision`。禁止无条件覆盖并发更新或直接写库存。
- 账本事件不可变，不存在“更新版本”；重复由事件 ID/幂等键识别。
- 列表与同步只用 opaque cursor；默认 50、最大 200（同步批量上限另行配置）。排序必须稳定并含唯一键兜底。

### 3.4 日期时间与金额

- 数据库存 UTC `timestamptz`，API 使用 ISO 8601 且必须带 offset/`Z`。禁止传无时区时间字符串。
- 客户端自然日由 `localDate` + `timezoneOffsetMinutes`/IANA timezone 表达；服务端接收时间不得替代行为发生时间。
- 金额使用整数最小货币单位或受限 decimal/numeric；API 字段显式写单位，如 `costFen`。禁止 float/double 持久化或比较金额。
- 历史金额按事件快照，不因资产现价改变；return 使用原 take 的金额相反数。

## 4. 数据验证与领域规则

### 4.1 资产

- 品牌必填、去除首尾空白、最多 16 字。
- 焦油 `1–20mg`；尼古丁 `0.1–3mg`；新增资产库存 `1–200` 整数；整包价 `1–200` 元。
- 每用户只能有一个未删除默认资产。切换时锁定用户父行，按“清除旧默认→设置新默认→写 change log”的顺序在同一短事务内完成，并由数据库部分唯一索引兜底；序列化失败/死锁只允许有限重试。
- 切换默认资产不改变资产展示顺序。被账本引用的资产只能软删除，历史快照仍可读。

### 4.2 账本与状态迁移

- 合法动作仅 `take`、`return`、`retire`。
- 已接受账本事件只追加、不原地修改、不硬删。纠错使用新补偿事件并保留关联和审计。
- `take`：库存至少为 1；接受事件与库存减 1 在同一事务。
- `return`：必须关联同用户、同资产、尚未被有效返回的 `take`；每次返回数量不能超过原取出未返数量；库存加回且净取出不得为负。
- `retire`：建议每资产一条事件并以 `batchId` 聚合；库存清零和事件追加同一事务。禁止用默认资产冒充其他资产的焦油/成本。
- 任何冲突不得通过篡改历史事件解决。若服务端拒绝离线事件，必须返回稳定冲突码，客户端保留本地记录和处理状态。

### 4.3 软删除、墓碑与审计

- 用户域可变资源用 `deletedAt` 软删除；pull 必须返回 tombstone。客户端不得用“列表里没有”推断删除。
- 账本不支持普通软删除；隐私删除在账户级数据生命周期流程中执行，并保留法律允许的最小审计证明。
- 管理员、高风险账户、设备撤销、导出、删除、迁移失败必须审计；审计元数据最小化并设保留期。

## 5. 同步冲突规则

### 5.1 不可变事件

- 账本采用 append-only；禁止 last-write-wins。
- 重复提交返回 `duplicate` 与原 canonical 结果，不再扣库存。
- 乱序事件以显式依赖处理。缺少 `reversesEventId` 目标时返回 `pending_dependency` 或受控暂存；不得猜测关联。同一批次内的显式依赖链应拓扑排序并按依赖组事务处理，互不依赖项允许逐项提交。
- 多设备同时消耗最后库存时，服务端只应用满足不变量的事务，其余返回 `LEDGER_STOCK_CONFLICT`。客户端本地记录不被静默删除。
- 同一 take 被两个设备 return 时，只允许第一个有效应用，后者返回 `LEDGER_RETURN_TARGET_ALREADY_REVERSED`。

### 5.2 可变资料

- 资产资料使用 `baseProfileVersion`，库存以账本和 `stockRevision` 收敛；目标、设置使用 `baseVersion`。无重叠字段可按明确规则合并；同字段冲突返回服务器当前值和版本。
- 禁止依据客户端墙上时钟做全对象 LWW。若某字段确需 LWW，必须经 ADR 明确时钟来源、偏差处理和审计。
- 默认资产冲突通过用户级事务和唯一约束解决；后提交者收到 canonical 默认资产，客户端 pull 后收敛。

### 5.3 游标与删除

- change cursor 单调、opaque、用户隔离。客户端整页持久化成功后才能推进游标。
- bootstrap 首请求固定 `snapshotSeq`；分页使用签名 snapshot token、稳定 keyset cursor，并只返回 `lastChangeSeq/changeSeq <= snapshotSeq` 的资源。水位后的完整 canonical change 必须由后续 pull 到达，禁止跨 HTTP 分页保持长数据库事务。
- 游标失效必须显式返回 `SYNC_CURSOR_EXPIRED` 并引导 bootstrap，禁止偷偷返回不完整增量。
- tombstone 的保留期不得短于所有受支持客户端的最大离线窗口；具体期限待确认。

## 6. 公式、模型与合规

- `todayPackYearIncrement = todayCigarettes / 20 / 365`。
- `healthMinutes = cigarettes * 20`。
- `stockPotentialPackYears = stockCount / 20 / 365`。
- `stockHealthDebtMinutes = stockCount * 20`。
- `netHealth = clamp(100 - lungScore, 0, 100)`；严禁使用 `100 - dailyHarmScore`。
- `dailyHarmScore` 仅用于当日行为风险，不能解释为长期健康净值。
- 风险快照必须包含不可变 `modelVersion`；算法升级发布新版本，不回写旧快照，不静默改变历史口径。
- 所有健康指标必须表达“非医学诊断，仅用于行为反馈/自我管理”。不得输出治疗建议、医疗恐吓、羞辱性内容或购买推荐。

## 7. 隐私、安全与日志

- 未经用户明确启用同步，不上传现有本地资产、账本、备注、设置或设备数据。
- 收集最小化；scene/note 只按用户输入同步，不用于广告画像。
- 密码只存强 hash；验证码只存短期 hash；refresh token 只存 hash 并轮换。令牌放客户端系统安全存储。
- TLS、静态加密、secret manager、最小权限数据库账户、按用途限流、依赖/镜像/secret 扫描为上线门禁。
- 所有查询按认证 `userId` 限定；禁止相信 body/path 中自报 `userId`。跨用户 IDOR 测试必须通过。
- 日志禁止包含密码、token、验证码、连接串、完整 note/scene、CSV 内容、删除/导出文件内容。错误日志必须脱敏。
- “重置本地数据”不触发云端删除。云端导出/删除需重新认证、独立确认、任务状态和审计。

## 8. 测试、迁移、发布与回滚门禁

### 8.1 测试门禁

- 单元：校验、公式、错误映射、冲突决策。
- 数据库集成：唯一默认资产、库存非负、return 唯一关联、事务回滚、墓碑、游标。
- API/E2E：认证、越权、幂等、乐观并发、分页、批量部分失败、账户高风险流程。
- 契约：OpenAPI lint、实现一致性、Harmony fixtures、breaking diff。
- 安全：依赖、SAST、secret、镜像扫描；认证/同步/导出/删除限流测试。
- 性能：常规 API、批量 push/pull、长账本分页和数据库慢查询。

### 8.2 数据库迁移

- 迁移文件只前进、可审查、不可在已共享环境改写历史；生产禁止 ORM 自动同步 schema。
- 每次迁移提供备份/恢复要求、向前兼容窗口、回滚或 roll-forward 方案和数据校验查询。
- 破坏性变更采用 expand → migrate/backfill → switch → contract；应用回滚期间新旧版本必须兼容。
- 历史 Harmony 数据迁移必须输出：总数、成功、legacy 标记、舍入差异、无法关联 return、失败原因；禁止静默丢弃。

### 8.3 发布与回滚

- 发布前必须通过 lint、typecheck、测试、migration smoke、OpenAPI diff、安全扫描、容器启动与 readiness。
- 发布前不得存在由项目源码触发的 NestJS/TypeScript 废弃 API 警告；第三方依赖的废弃提示需记录来源、影响、升级路径和处理期限。
- 数据库先做兼容性扩展，应用灰度/滚动发布；监控错误率、p95、同步冲突和数据库资源。
- 应用回滚不得依赖降级数据库 schema。不可逆数据迁移优先 roll-forward，并预先演练。
- 每阶段报告必须如实列出未验证项；“编译通过”不得写成“设备/生产验证通过”。

### 8.4 华为云部署规则

- **【已确认事实】** 华为云是优先部署平台；只确认账号可用，不得据此声称地域、配额、备案、域名、VPC、RDS、CAE/CCE 或生产环境已存在。
- **【建议选型】** MVP 优先评估 `CAE + SWR + RDS for PostgreSQL + LTS/AOM`；需要 Kubernetes 能力时再评估 CCE。最终拓扑与 PostgreSQL 17/18 选择必须通过 [ADR-012](./adr/ADR-012-huawei-cloud-deployment.md)。
- 云资源必须通过 IaC 可重复创建，至少隔离 `dev/staging/prod`；IAM 使用最小权限，数据库只走私网，应用账户无 DDL 权限，migration 使用独立受控身份。
- GitHub Actions 到华为云优先使用短期凭据/联邦身份；若平台限制只能使用 AK/SK，必须存入受保护 Secret、限制权限并制定轮换，不得写入仓库、镜像、日志或报告。
- SWR 镜像以 commit SHA 和 digest 标识，禁止复用可变生产标签作为唯一发布证据；发布记录必须能追溯源码、lockfile、SBOM、扫描结果和 migration。
- 华为云 RDS 的数据库主版本及规格以目标地域控制台和官方文档为准。当前公开购买文档最高为 PostgreSQL 17；不得在未验证兼容性时把 PostgreSQL 18 migration 直接部署到 RDS 17。
- LTS/AOM/CES 日志、指标和告警仍受本文件的数据最小化与脱敏规则约束；接入云日志不构成扩大采集范围的授权。

## 9. 禁止项

- 禁止把严厉危害通知改成服务端阻塞、远程审批或取烟失败条件。
- 禁止在未授权时上传、扫描或推断用户本地数据。
- 禁止让核心手机记账等待网络或登录。
- 禁止浮点持久化金额，禁止模糊金额单位。
- 禁止跨用户读写、仅凭对象 ID 授权或信任客户端 `userId`。
- 禁止修改/删除已接受账本事件来“解决”冲突，禁止对账本使用全对象 LWW。
- 禁止 return 没有原 take 关联，禁止库存或今日净取出为负。
- 禁止一个用户存在多个默认资产，禁止切换默认项时重排资产。
- 禁止用服务端接收时间覆盖行为发生时间，禁止无时区时间。
- 禁止用 `100 - dailyHarmScore` 计算健康净值。
- 禁止静默改变、重算或破坏历史模型版本与风险快照。
- 禁止把“重置本地数据”解释为“删除云端账户数据”。
- 禁止日志记录 token、验证码、密码、完整备注、导出内容或密钥。
- 禁止虚构已存在的后端代码、数据库、域名、云资源、短信供应商或发布环境。
- 禁止在 NestJS 11 代码中引入已废弃 API，或为通过编译而关闭相关类型/静态检查。

## 10. 验收规则

### 10.1 与 Harmony 一致的规则

- 资产表单边界与错误可定位；默认资产唯一、持久化语义明确且不改变顺序。
- take 扣库存并追加账本；取消不产生服务端写；return 撤销一次真实成本并关联原 take；retire 可审计。
- 严厉警示不阻止取烟，通知失败不影响记录；每日复盘仍为客户端本地能力。
- 今日指标按客户端本地自然日；历史不混入今日。
- CSV/事件包含时间、动作、品牌、焦油、成本、健康折算、备注；金额和时间口径明确。
- 健康净值只使用 `100 - lungScore`；所有健康指标有非医学诊断边界。

### 10.2 后端专属验收清单

- [ ] 匿名/未登录 Harmony 客户端核心路径不依赖后端。
- [ ] 未启用同步时无本地数据上传请求。
- [ ] OpenAPI lint、breaking diff、实现契约测试通过。
- [ ] 相同幂等请求不重复扣库存；同键异 body 返回冲突。
- [ ] 幂等缓存过期后重放同一 `clientMutationId` 仍不重复应用账本事件。
- [ ] 并发切换默认资产最终仅一个默认项。
- [ ] take 只推进 `stockRevision`，不会导致资产资料发生伪版本冲突。
- [ ] 并发 take/return 不产生负库存或重复返回。
- [ ] 账本事件不可 PATCH/DELETE，补偿事件可追溯。
- [ ] push 支持逐项 applied/duplicate/conflict/pending，pull 游标稳定，墓碑可达。
- [ ] bootstrap 分页与后续 pull 无遗漏窗口，水位后更新以完整 canonical change 到达。
- [ ] 跨用户资产、账本、设备、导出、删除访问全部拒绝且不泄露存在性。
- [ ] 云端导出与删除有重新认证、确认、审计和可查询任务状态。
- [ ] migration 在空库、前一版本数据和回滚/roll-forward 演练中通过。
- [ ] 日志脱敏、安全扫描、备份恢复演练和 SLO 监控满足发布门禁。

未满足任一强制项时不得宣称对应阶段完成。报告格式与阶段节奏见 [后端实施计划](./backend_implementation_plan.md)。
