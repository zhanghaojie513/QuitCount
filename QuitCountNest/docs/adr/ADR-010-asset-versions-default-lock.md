# ADR-010：资产双版本与默认资产用户行锁

- 状态：accepted
- 日期：2026-07-14
- 责任角色：后端负责人、DBA

## 决策

资产使用两个独立并发版本：

- `profileVersion`：品牌、焦油、尼古丁、整包价、默认状态和软删除等可变资料。
- `stockRevision`：仅由账本事务推动的库存物化版本。

资料更新比较 `baseProfileVersion`，不能携带或直接覆盖库存；take/return/retire 比较库存条件并递增 `stockRevision`，不制造资料伪冲突。

切换默认资产时锁定所属用户父行，在同一短事务内清除旧默认、设置新默认、递增资料版本并写 change log。数据库使用“每用户至多一个未删除默认资产”的部分唯一索引兜底。死锁/序列化失败只有限重试，最终返回稳定冲突。

## 删除与顺序

被账本引用的资产软删除；历史快照仍可读。切换默认项不得更改资产展示顺序。若删除默认资产，客户端必须显式选择替代项，或服务端按已批准产品规则返回冲突；当前不静默选择。

## 验证

并发切换默认资产最终至多一个默认项；take 与编辑资料并发互不覆盖；直接写 `stockCount` 的 DTO/SQL 被拒绝。
