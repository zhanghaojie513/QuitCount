# ADR-007：可选账户与认证升级路径

- 状态：proposed
- 日期：2026-07-14
- 责任角色：产品负责人、安全负责人
- 决策截止：Stage 3 开始前

## 已冻结边界

- Harmony 首版不强迫登录；未启用同步的本地数据不上传。
- 启用云同步时才创建/绑定账户和设备，并显式确认上传范围。
- access token 短时有效；refresh token 轮换、只存 hash、可按设备撤销。
- 密码只存强 hash；验证码只存短期 hash。API 不在 URL 传 token。
- 认证主体来自已验证 token，服务端不信任 body/path 自报 `userId`。
- 从匿名/临时账户升级为正式账户时必须保持同一数据所有权，并审计合并/拒绝结果。

## 待确认决策

首期登录方式（邮箱、短信、第三方或匿名账户升级）、供应商、凭证恢复、MFA 范围、token TTL 与部署地区仍未确认。OpenAPI 当前使用抽象的登录/刷新/注销 DTO，不承诺短信供应商或域名。

## 选择标准

数据最小化、国内/目标地区可用性、供应商退出路径、限流/反滥用、账户恢复安全、成本和合规。任何选择需补充威胁模型和数据处理清单。

## 阻塞条件

在本 ADR 接受前，Stage 3 不得接入真实验证码/身份供应商或开放账户 API；Stage 0 契约仅为草案。
