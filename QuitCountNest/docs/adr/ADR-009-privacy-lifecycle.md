# ADR-009：云端导出、删除、保留和备份恢复

- 状态：proposed
- 日期：2026-07-14
- 责任角色：隐私/法务、运维负责人
- 决策截止：Stage 7 开始前

## 已冻结边界

- “重置本地数据”不等于删除云端账户数据，二者使用独立文案、入口和操作。
- 云端导出/删除是高风险异步任务：重新认证、二次确认、幂等、状态查询、审计。
- 删除流程先撤销会话和设备，再按数据地图删除/匿名化；不能由普通资源 DELETE 代替。
- 备份中的数据按既定周期自然过期，恢复后必须重放删除标记，避免数据复活。
- 审计只保留法律允许的最小证明，不保存完整 note、导出内容或 token。

## 待确认决策

部署地区、适用法域、数据保留期、删除冷静期、导出格式/有效期、审计保留期、RPO/RTO、备份加密与恢复责任人。以上必须由责任角色在 Stage 7 前接受，当前文档不承诺具体 SLA。

## 验证

Stage 7 完成数据流清单、导出完整性测试、删除后访问测试、备份恢复后删除重放演练和审计脱敏检查。
