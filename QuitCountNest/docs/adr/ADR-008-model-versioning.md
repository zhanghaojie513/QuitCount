# ADR-008：模型版本和历史快照不可变

- 状态：accepted
- 日期：2026-07-14
- 责任角色：产品负责人、后端负责人

## 决策

每个风险快照必须包含 `modelVersion`。账本事件接受时保存完整风险输入/输出快照，包括 `lungScore`、`netHealth`、`dailyHarmScore`、健康负债和库存口径。

健康净值固定为 `clamp(100 - lungScore, 0, 100)`，不得使用 `100 - dailyHarmScore`。算法升级发布新 `modelVersion`，只作用于新计算；不静默回写历史事件。

若产品需要“按新模型重看历史”，必须作为单独派生视图标明新旧版本，不覆盖原始快照。所有输出带“非医学诊断，仅用于行为反馈/自我管理”边界。

## 版本格式

使用稳定字符串，如 `quit-risk/1.0.0`；语义改变递增版本。服务端模型注册表记录生效时间、公式摘要和兼容说明，但不把算法版本等同于 API 版本。

## 验证

契约示例必须含 `modelVersion`；回归 fixture 固定输入输出；模型升级测试证明旧事件序列化结果不变。
